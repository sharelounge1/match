자기소개

안녕하세요, 5년차 풀스택 개발자 박개발입니다. 저는 그동안 헬스케어 분야의 스타트업에서 근무하며 피트니스 앱과 건강 관리 서비스를 개발한 경험이 있습니다. 특히 사용자 데이터를 기반으로 한 개인화 추천 시스템에 관심이 많고, 이번 프로젝트의 AI 운동 추천 컨셉에 크게 매력을 느꼈습니다. React Native를 활용한 크로스플랫폼 앱 개발과 Node.js 기반 백엔드 구축에 능숙하며, Python을 활용한 데이터 처리 및 ML 모델 연동 경험도 있습니다.

관련 경험

- FitLife 앱: 운동 기록 및 목표 달성 트래킹 앱 풀스택 개발 (React Native + Node.js) - HealthMate: 건강 데이터 수집 및 분석 대시보드 개발 - 개인 프로젝트: TensorFlow를 활용한 운동 자세 분석 POC 특히 FitLife 앱에서는 사용자의 운동 패턴을 분석하여 다음 운동을 추천하는 기능을 직접 설계하고 구현했습니다.

기여 계획

1. 앱 아키텍처 설계 및 기술 스택 선정 지원 2. React Native 기반 프론트엔드 개발 주도 3. 백엔드 API 설계 및 데이터베이스 모델링 4. AI/ML 모델 연동 및 추천 알고리즘 구현 지원 5. 웨어러블 기기 연동 기능 개발 주 25시간 이상 안정적으로 참여 가능하며, 정기 미팅 시간에 맞춰 소통하겠습니다.
