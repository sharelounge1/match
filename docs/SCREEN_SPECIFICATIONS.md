#### UI 구성요소

```
┌─────────────────────────────────┐

│  ┌───────────────────────────┐  │

│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │ 비밀번호           [👁️]   │  │
│  └───────────────────────────┘  │
│                                 │
│  [      로그인 버튼       ]     │
│                                 │
│  비밀번호를 잊으셨나요?          │
│                                 │
│  ─────── 또는 ───────          │
│                                 │
│  [G] Google로 계속하기           │
│  [GH] GitHub로 계속하기          │
│  [K] 카카오로 계속하기           │
│                                 │
│  계정이 없으신가요? 회원가입      │
└─────────────────────────────────┘
```

#### 기능 상세

| 기능 | 설명 |
|------|------|
| 이메일/비밀번호 입력 | 필수 입력, 실시간 유효성 검사 |
| 비밀번호 표시/숨김 | 👁️ 아이콘 토글 |
| 로그인 버튼 | 입력값 검증 후 로그인 API 호출 |
| 비밀번호 찾기 | `/auth/forgot-password`로 이동 |
| 소셜 로그인 | OAuth 팝업 → 콜백 처리 |
| 회원가입 링크 | `/auth/signup`으로 이동 |

#### 프로세스 흐름

1. 사용자가 이메일/비밀번호 입력
2. 로그인 버튼 클릭
3. 입력값 유효성 검사
4. Supabase Auth API 호출
5. 성공 시 JWT 저장 → 온보딩 또는 홈으로 이동
6. 실패 시 에러 토스트 표시

#### 에러 처리

| 에러 상황 | 메시지 |
|----------|--------|
| 이메일 형식 오류 | "올바른 이메일 형식을 입력해주세요" |
| 비밀번호 미입력 | "비밀번호를 입력해주세요" |
| 인증 실패 | "이메일 또는 비밀번호가 올바르지 않습니다" |
| 이메일 미인증 | "이메일 인증을 완료해주세요" |
| 네트워크 오류 | "네트워크 오류가 발생했습니다. 다시 시도해주세요" |
